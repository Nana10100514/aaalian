Alien Camera — 紙の絵を読み取る版（瞬き・浮遊アニメーション付き）

【設定】
1. ZIPを展開してください。
2. 中の index.html・styles.css・app.js を、今のプロジェクトの同名ファイルに上書きしてください。
3. assets フォルダの中身をすべて追加・上書きし、vendor フォルダも追加してください。
4. 表示用の alien-open.png と alien-closed.png は、今回のPDFから変換した透過PNGを同梱しています。
   同じ寸法・同じ位置で書き出しているため、瞬きで体の位置がずれません。
   target.png は先に送っていただいた読み取り用の画像です。
5. HTTPSの公開URLで開いてください。GitHub Pagesの既存プロジェクトにも追加できます。
   HTMLをパソコンで直接ダブルクリックして開く方法では動作しません。

【紙に印刷するとき】
同封の assets/target.png をカラー印刷してください。
まずは幅10〜15cmほど、光沢のない紙で試すと位置を合わせやすくなります。
絵を切り抜いたり、白い余白を変更したりせず、画像全体を印刷してください。
別の絵に変更する場合は、認識用の target.mind も作り直す必要があります。

【遊び方】
1. スマホで公開URLを開き、カメラを許可します。
2. 「宇宙人の絵をカメラに映してね」が表示されるまで待ちます。
3. 紙の絵全体をカメラに映し、少し静止します。
4. 認識すると宇宙人が画面中央に出現します。
5. 宇宙人は約3秒周期で上下に浮遊し、約2〜4秒おきに短く瞬きします。
   1本指で移動、2本指で拡大縮小し、下の白いボタンで撮影します。
   指で操作している間は上下の浮遊位置を固定し、指を離すと再開します。
6. 撮影画面の保存ボタンでPNGを保存します。
   iPhoneで保存画面が開いた場合は、画像の長押しや共有メニューから保存してください。
7. 「もう一度読み取る」で宇宙人を消し、再び読み取りを始められます。

一度認識した後は、紙を画面から外しても宇宙人が残ります。
紙の位置や傾きに追従する表示ではなく、認識をきっかけにした写真用の表示です。
紙の影・光の反射・印刷の色・撮影距離によって認識率は変わります。
認識しづらい場合は明るい場所で紙を正面から映し、少し近づけてください。

【確認できたこと】
認識用データの生成と読み込み、正面・約9度回転・縮小した合成テスト画像の認識、
無地のテスト画像では認識しないことを確認しました。
アプリの制御テストで、未認識時は出現しないこと、認識後の出現・撮影・再読取を確認しました。
実際のスマートフォンのカメラ、印刷物、指操作、写真アプリへの保存は実機で未確認です。
